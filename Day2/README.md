## Student Record Management System (Version 1)

Implemented in [student_management.py]

### Features
1. **Add Student**: Add student details (Roll Number, Name, Age, Course) with duplicate checking and input validation.
2. **View All Students**: Displays tabular record summary and total count of enrolled students.
3. **Search Student**: Quick lookup by Roll Number.
4. **Update Student Information**: Modify existing records while keeping unchanged fields intact.
5. **Delete Student Record**: Remove student record by Roll Number with confirmation prompt.
