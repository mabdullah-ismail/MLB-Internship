# Student Grading System

A simple, interactive command-line Python application that calculates a student's overall average and letter grade based on their subject marks.

## Features

- **Student Details**: Prompt for student name and class.
- **Dynamic Subjects**: Enter any number of subjects and their names.
- **Input Validation**: Ensures marks are entered between `0` and `100`.
- **Grade Calculation**: Calculates the average score and assigns grades:
  - **A**: 90% and above
  - **B**: 80% to 89%
  - **C**: 70% to 79%
  - **D**: 60% to 69%
  - **F**: Below 60%
- **Grade Card Summary**: Displays a clean summary output.

## How to Run

1. Make sure you have **Python 3** installed.
2. Run the script:

```bash
python gradingSystem.py
```
